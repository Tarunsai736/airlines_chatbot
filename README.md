# ✈️ Airline AI Chatbot

An AI-powered airline customer support chatbot built using:

- Python
- Streamlit
- Google Gemini
- Conversation Memory
- AI Guardrails
- Fallback Handling
- Human Escalation

## Features

- Airline-only question handling
- Gemini-powered responses
- Conversation memory
- Input guardrails
- Fallback mechanism
- Human escalation
- Error handling
- Secure API key management
- Streamlit interface
